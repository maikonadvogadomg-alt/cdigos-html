1. Visão Geral

O Iara Suite v2.0 é uma suite de ferramentas para desenvolvimento e produtividade jurídica que funciona 100% no navegador, sem dependência de servidores externos, sem instalar nada e sem qualquer vínculo com o servidor Replit.

💻 Code Editor

Editor de código com sistema de arquivos virtual, importação de ZIPs, e assistente de IA (Jasmim) conectado diretamente a qualquer provedor via chave de API.

🖥 Terminal Linux

4 opções de terminal Linux online gratuito. O WebVM roda Alpine Linux completo via WebAssembly no navegador — sem servidor, sem conta, sem instalação.

📦 APK Builder

Converte qualquer site/app em ZIP de projeto Android (Capacitor) ou executável PC (Electron). Inclui GitHub Actions para compilar o APK automaticamente na nuvem.

🔍 Site Extractor

Extrai scripts de cálculo de sites jurídicos via proxy público. Identifica automaticamente fórmulas, AJAX e lógica previdenciária.

✅ Sem dependências externas: nenhuma chamada ao servidor Replit em nenhuma hipótese. A IA chama diretamente o servidor do provedor (OpenAI, Anthropic, Google, Groq etc). O terminal usa WebAssembly local.

2. Requisitos e Instalação

Para usar o Iara Suite

  • Qualquer navegador moderno: Chrome 90+, Firefox 88+, Edge 90+, Safari 15+
  • Conexão com internet apenas para: IA, Terminal, Site Extractor
  • O Code Editor e APK Builder funcionam offline

Para compilar o APK (depois de gerar o ZIP)

Via Android Studio

  • Android Studio Hedgehog+
  • Java 17+ (JDK)
  • Android SDK 34
  • Node.js 18+
  • ~8 GB de espaço em disco

Via GitHub Actions (recomendado)

  • Conta gratuita no GitHub
  • Repositório público (grátis)
  • Push do código → APK gerado em ~10 min
  • Sem instalar Android Studio!

Como abrir

1
Extraia o arquivo iara-suite.zip
2
Windows: clique duas vezes em iniciar.bat
2b
Mac/Linux: execute ./iniciar.sh no terminal
2c
Alternativa: arraste index.html para qualquer navegador

3. Code Editor

O editor possui um sistema de arquivos virtual salvo no localStorage do navegador. Os arquivos persistem entre sessões.

Gerenciar Arquivos

  • Digite o nome no campo superior da barra lateral e pressione Enter ou clique +
  • Clique em qualquer arquivo para abrir
  • Clique no ✕ vermelho para deletar (confirme o popup)
  • Ctrl+S salva o arquivo atual
  • Tab insere 2 espaços (não perde o foco)

Importar / Exportar ZIP

  • 📥 ZIP (barra lateral) — importa todos os arquivos de um ZIP
  • 📤 ZIP (barra lateral) — exporta todos os arquivos em um ZIP
  • Compatível com ZIPs de projetos React, Vue, Next.js, HTML puro etc.

IA Integrada — Jasmim

Clique em 🤖 IA na barra do editor para abrir o chat.

  • Enviar ↵ ou Ctrl+Enter envia a mensagem
  • 📋+código — envia a mensagem com o conteúdo do arquivo atual
  • ⬅ código — insere o último bloco de código da IA no editor
  • 🗑 — limpa o histórico do chat
💡 Dica: A IA Jasmim é especializada em cálculos previdenciários, INSS, RGPS e desenvolvimento jurídico. Peça: "Calcule a aposentadoria por tempo de contribuição com fator previdenciário" ou "Gere uma calculadora de atualização monetária com IPCA".

5. Terminal Linux Online

O Iara Suite inclui 4 opções de terminal Linux gratuito, acessíveis na aba 🖥 Terminal Linux. Nenhum usa o servidor Replit.

WebVM (Recomendado)

WebVM — Alpine Linux completo via WebAssembly + CheerpX. Roda 100% no seu navegador, sem servidor externo. Suporta: bash, python3, gcc, node, npm, vim, curl e muito mais.
  • URL: webvm.io
  • Sistema: Alpine Linux 3.19
  • Sem conta, sem login, sem limite de tempo
  • Pode instalar pacotes: apk add python3 nodejs npm
  • Acesso à internet dentro do VM via Tailscale (opcional)

Outras Opções

Nota: O terminal externo abre em um iframe. Alguns sites bloqueiam iframe por política X-Frame-Options. Se não carregar, clique o link para abrir em nova aba.

6. APK Builder

O APK Builder converte qualquer site/app web em um projeto Android (APK) ou executável de PC (Electron), gerado 100% no navegador sem servidor.

Importante: O APK Builder gera o projeto de código-fonte compactado em ZIP. Para compilar o APK (.apk), você precisa do Android Studio ou do GitHub Actions (opção mais fácil).

Opção A — Capacitor + Android Studio

1
Na aba APK Builder, arraste o ZIP do seu site (ou clique para selecionar)
2
Preencha Nome do App e Package ID (ex: br.adv.maikoncaldeira.app)
3
Configure Versão, Cor, Orientação e Android mínimo
4
Selecione 📱 Capacitor + Android Studio
5
Clique ⚡ Gerar ZIP do Projeto — faz o download automaticamente
6
Extraia o ZIP e execute no terminal:
npm install
npx cap copy android
7
Abra o Android Studio → File → Open → selecione a pasta android/
8
Aguarde o Gradle sync (~5 min na primeira vez)
9
Build → Build Bundle(s)/APK(s) → Build APK(s)
10
APK gerado em: android/app/build/outputs/apk/debug/app-debug.apk

Opção B — GitHub Actions (sem instalar nada)

Esta é a opção mais fácil. O APK é compilado automaticamente no GitHub quando você faz push.

1
Siga os passos 1 a 5 da Opção A para gerar o ZIP
2
Extraia o ZIP e inicialize o repositório Git:
git init
git add .
git commit -m "Initial commit"
3
Crie um repositório no GitHub.com (pode ser público, gratuito)
4
Faça o push:
git remote add origin https://github.com/SEU-USUARIO/SEU-REPO.git
git branch -M main
git push -u origin main
5
O GitHub Actions inicia automaticamente. Aguarde ~10-15 minutos
6
Acesse a aba Releases do repositório → clique no arquivo .apk para baixar
💡 Dica: Toda vez que fizer push (com atualizações), o APK é recompilado automaticamente. O workflow já está configurado no arquivo .github/workflows/build-apk.yml.

Instalar o APK no celular

  1. Transfira o .apk para o celular (cabo USB, WhatsApp, Google Drive)
  2. No celular: Configurações → Segurança → Fontes desconhecidas (ou similar)
  3. Abra o arquivo .apk e toque em Instalar

Opção C — Electron (Executável de PC)

1
Selecione 🖥 Electron (PC: Win/Mac/Linux)
2
Gere e extraia o ZIP
3
Instale Node.js e execute:
npm install
npm start          # Abre o app
npm run dist       # Gera .exe (Windows), .dmg (Mac), .AppImage (Linux)
4
O executável é gerado na pasta dist-electron/

7. Site Extractor

O Site Extractor acessa páginas web via proxies públicos gratuitos para contornar restrições de CORS, permitindo analisar scripts de cálculo de sites jurídicos.

Proxies Públicos Utilizados

  1. allorigins.win — proxy primário, retorna JSON com HTML
  2. corsproxy.io — fallback automático se o primeiro falhar
  3. codetabs.com/v1/proxy — terceiro fallback
Sites com Cloudflare Enterprise ou WAF avançado podem bloquear proxies. Nesse caso, experimente acessar o site e inspecionar manualmente o HTML via F12 → Fontes.

Scripts de Cálculo Detectados

O extrator identifica automaticamente scripts com:

  • ⚖️ Cálculo — palavras como: salário, benefício, INSS, previdenciário, aposentadoria, pensão, correção monetária, coeficiente, RMC
  • 📐 Fórmula — Math., parseFloat, toFixed, function calc, operações matemáticas
  • 🌐 AJAX/Fetch — fetch(), XMLHttpRequest, $.ajax(), axios

Funcionalidades

  • ⬇ .js — baixa todos os scripts inline em um arquivo JavaScript
  • ⬇ HTML — baixa o HTML completo da página
  • 👁 Ver — abre o código do script em modal com opção de copiar
  • 🔗 — abre o arquivo externo em nova aba
  • Profundidade 2 — extrai também subpáginas (até 5 links)

9. FAQ — Perguntas Frequentes

O app usa o servidor do Replit de alguma forma?

Não. Nenhuma chamada vai ao Replit. A IA chama diretamente o servidor da provedora (OpenAI, Groq, etc). O terminal usa WebVM (WebAssembly local). O extrator usa proxies públicos independentes.

Minha chave de API fica segura?

A chave é salva apenas no localStorage do seu navegador (no seu dispositivo). Ela nunca é enviada a nenhum servidor intermediário — vai direto da sua máquina para o servidor do provedor (OpenAI, Groq, etc).

O APK Builder gera o APK automaticamente?

O APK Builder gera o projeto de código-fonte em ZIP. Para gerar o arquivo .apk instalável, use o Android Studio (local) ou o GitHub Actions (automático na nuvem). O processo via GitHub Actions é mais simples — sem instalar nada.

Posso converter o Iara Suite em APK?

Sim! Na aba APK Builder, clique Demo (Iara Suite). Isso carrega o próprio app com configuração br.adv.maikoncaldeira.iarasuite e orientação "Ambas". Gere o ZIP e compile normalmente.

O Terminal Linux funciona offline?

O WebVM roda Alpine Linux via WebAssembly. Ele precisa de conexão inicial para carregar (~10 MB), mas depois funciona parcialmente offline. Para acesso à internet dentro do VM, configure o Tailscale (opcional).

O Site Extractor não conseguiu acessar um site. O que fazer?

Sites com proteção Cloudflare podem bloquear proxies. Opções: (1) tente a URL sem www; (2) use a profundidade 1; (3) acesse o site manualmente no navegador e salve a página (Ctrl+S), depois extraia o HTML salvo.

Posso usar múltiplas IAs simultaneamente?

Configure os 4 slots com chaves diferentes. Apenas um slot pode estar ativo por vez. Para trocar, abra 🔑 Chaves API, ative outro slot e salve.
