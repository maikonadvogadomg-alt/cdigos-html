🏗️ Ferramenta 3: Entender Estrutura Replit

ℹ️ Estrutura típica de um projeto Replit
📁 projeto-replit/
📁 .replit
├─ replit.nix (configuração)
├─ .gitignore
📁 .git
├─ commits (histórico)
├─ branches (versões)
📁 .history
├─ arquivo.js.bak (backup automático)
├─ package.json.bak
📁 node_modules/
├─ dependências instaladas
📁 dist/ ou build/
├─ arquivo.min.js (minificado)
├─ index.html
📄 package.json
📄 index.js (entry point)
✅ Pastas Importantes:

.git = Histórico completo de versões

.history = Backups automáticos de arquivos

.replit = Configuração do projeto

dist/build = Código minificado/otimizado

ℹ️ Como Replit otimiza builds
✅ Técnicas de Otimização:

1. Minificação: Remove espaços e comentários

2. Tree Shaking: Remove código não usado

3. Code Splitting: Divide em chunks menores

4. Compression: Gzip/Brotli

ℹ️ Como criar APK pequeno (React Native/Flutter)
⚠️ Requisitos:

Node.js 16+

Android SDK

React Native ou Flutter instalado

✅ Passos para APK Pequeno:

1. Remova dependências desnecessárias

2. Use ProGuard/R8 para ofuscação

3. Ative minificação

4. Comprima assets

5. Use split APKs por arquitetura
